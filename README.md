# Конкурс «Корпоративная история» — Феерия.ру

Статический лендинг конкурса: этап по датам, сроки, призы, баллы
(1 голос = 10 баллов, видео до 60 секунд = 500 баллов), правила, кнопки входа
через VK ID и Сбер ID.

## Файлы

```
index.html         — разметка
konkurs.css        — стили страницы
konkurs.js         — этапы по датам, сроки, кнопки; настройки в объекте CONFIG
assets/styles.css  — общие стили Феерия.ру (шапка, кнопки, подвал)
```

## Запуск локально

```
npm start
# или
python3 -m http.server 5173
```

Открыть http://localhost:5173

Проверить этап без ожидания дат: `/?now=2026-11-27T12:00:00+03:00`.

## Настройки

В начале `konkurs.js` объект `CONFIG`: даты этапов (московское время) и адреса
сервиса (`endpoints.loginVk`, `endpoints.loginSber`, `endpoints.rules`). Пока
адреса пусты, кнопки входа неактивны.

## Чего здесь нет

Регистрация, карточки компаний, загрузка видео и голосование через VK ID и
Сбер ID требуют серверной части и в этот репозиторий пока не входят.
