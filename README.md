# Конкурс «Битва компаний за салют» — Феерия.ру

Лендинг конкурса и сервис для регистрации компаний, модерации, видео и голосования
через VK ID и Сбер ID.

## Механика (как реализовано)

- Капитан входит через VK ID или Сбер ID, даёт согласие на обработку ПДн и заполняет анкету:
  название, город, рассказ, телефон и e-mail. Контакты видит только организатор.
  Регистрация открыта с 11 по 25 ноября. Один аккаунт — одна компания.
- Организатор одобряет заявку или отклоняет с причиной. Капитан может исправить отклонённую
  заявку и отправить заново, пока открыта регистрация.
- После одобрения появляется публичная карточка `/c/<код>`. Это и есть ссылка для голосования.
- Видео до 60 секунд загружается в кабинете капитана в те же даты, что и регистрация.
  Длительность проверяется автоматически (ffprobe). После проверки организатором компания
  получает 500 баллов, один раз.
- Голосование открыто с 26 ноября 00:00 по 5 декабря 23:59:59 по Москве. До старта кнопка
  неактивна, и сервер не принимает голоса даже в обход кнопки.
- **Один голос на человека за весь конкурс.** Для голоса нужен подтверждённый телефон
  в аккаунте VK ID или Сбер ID. Хранится не номер, а его отпечаток (HMAC). Один номер —
  один голос, через какой бы сервис человек ни вошёл. Это ограничение уникальности стоит
  прямо в базе данных.
- Капча Yandex SmartCaptcha. С каждым голосом сохраняются точное время (до микросекунд),
  IP, браузер, referer и UTM-метки.
- Баллы = засчитанные голоса × 10 + 500 за принятое видео. Три компании с наибольшей суммой
  побеждают. При равенстве выше та, что раньше набрала итоговую сумму: момент её последнего
  засчитанного голоса или принятия видео, смотря что позже. Если совпало и это (до
  микросекунды), админка показывает предупреждение: жребия нет.
- Итоги на `/results` видны только после того, как организатор нажмёт «Опубликовать».

## Страницы

| Адрес | Что это |
|---|---|
| `/` | лендинг (`index.html`, `konkurs.js`, `konkurs.css`) |
| `/companies` | галерея одобренных компаний |
| `/c/<код>` | карточка компании и голосование |
| `/rating` | рейтинг (открывается вместе с голосованием) |
| `/results` | итоги (после публикации) |
| `/my` | кабинет капитана: анкета, статус, ссылка, видео |
| `/login/vk`, `/login/sber` | согласие и вход |
| `/admin` | админка: заявки, видео, голоса (аннулирование, CSV), дисквалификация, итоги, журнал |
| `/api/contest` | даты и включённые способы входа для лендинга |

## Код

```
src/
  server.js            запуск
  app.js               сборка приложения
  config.js            все настройки из переменных окружения, даты этапов
  db.js, migrations/   PostgreSQL и схема
  auth/providers.js    VK ID, Сбер ID (+ тестовый вход только для разработки)

test/                  тесты (node:test)

```

## Запуск на сервере (Docker)

1. Скопировать `.env.example` в `.env`, заполнить. Секреты хранятся только в `.env`.
2. Сертификат Сбер ID (`.p12`) положить в `secrets/`. Папка не попадает в git.
3. Запустить:
   ```
   docker compose up -d --build
   docker compose exec app node src/cli/create-admin.js org
   ```
4. Настроить nginx с HTTPS по примеру `deploy/nginx.conf`.
5. В кабинетах VK ID и Сбер ID указать адреса возврата:
   `https://<домен>/auth/vk/callback` и `https://<домен>/auth/sber/callback`.

База и видео хранятся в Docker-томах `pgdata` и `videos` на диске сервера. Делайте их
резервные копии, например `docker compose exec db pg_dump -U konkurs konkurs > backup.sql`.

Без `PHONE_HASH_SECRET` и ключей SmartCaptcha сервис в боевом режиме не запустится.
Кнопка входа появляется на лендинге автоматически, когда для провайдера заданы ключи.

## Разработка

Нужны Node.js 22, PostgreSQL и ffmpeg.

```
npm install
DATABASE_URL=postgres://user@localhost/konkurs DEV_LOGIN=1 npm run dev
```

`DEV_LOGIN=1` включает тестовый вход без VK и Сбера (в боевом режиме он отключён всегда).
Капча в разработке отключена.

Тесты (используют отдельную базу и стирают её):

```
TEST_DATABASE_URL=postgres://user@localhost/konkurs_test npm test
```

Только статический лендинг без сервиса: `npm run static`, проверка этапа: `/?now=2026-11-27T12:00:00+03:00`.

## Что нужно сверить перед запуском

- **Адреса и поля VK ID и Сбер ID.** Значения по умолчанию в `src/config.js` и `.env.example`
  взяты из публичного описания API. Проверить их по документации из среды разработки
  не удалось. Перед запуском сверить в кабинетах: адреса авторизации и токена, название
  прав доступа к телефону (VK: `phone`, Сбер: `mobile`), поля `user.phone` (VK)
  и `phone_number` (Сбер) в ответе. Всё переопределяется через `.env`.
- **Тексты для юриста.** Экран согласия при входе, галочка согласия на публикацию в анкете,
  подсказки о лимите голосов. Ссылки на документы задаются через `RULES_URL`, `PRIVACY_URL`,
  `CONSENT_URL`.
